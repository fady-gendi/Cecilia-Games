CECILIA GLOBAL ACCOUNT — VERSION 2.4

The live game files share coins immediately on the same browser/device.
Cloud sharing across devices needs this one-time backend deployment.

1. Create a NEW Apps Script project at script.google.com. Do not replace the
   existing Word Garden project. Paste Global_Wallet_CodeGS.txt into Code.gs.
2. Run setupGlobalWallet once and approve access. It creates a new private
   spreadsheet with Ledger and Game_Saves tabs. Existing games/sheets are untouched.
3. Open Project Settings > Script properties. Copy FAMILY_KEY privately.
4. Deploy > New deployment > Web app. Execute as: Me. Access: Anyone.
   Copy the resulting /exec URL.
5. On Cecilia’s Games open the shared coin account > Parent > cloud connection.
   Paste the /exec URL and FAMILY_KEY. Connect, wait for “Cloud synced ✓”.
   Do this on each device using the SAME URL and family key. Reload games afterwards.

Educational balances are imported once per source, using a maximum migration
credit to avoid counting the same legacy balance twice on different devices.
Math Quest’s existing solved problems convert at 10 coins each once. New
answers earn 10 coins plus 5 for solving without help. First-time level
completion adds 30 coins, with 20 extra for a completely independent level.
Legacy language-game rewards, hints and sticker prices use the global wallet.
Little World spends from that wallet; its old starter coins and repeatable
cupcake coin rewards no longer mint currency. Existing objects are retained.

Stars, levels and trophies stay in the individual game progress. They are not
spendable currency. Fashion Studio displays the same coin balance without
awarding coins for non-educational free play.

Cloud ledger changes are serialized with LockService and use unique transaction
IDs for safe retry. The server rejects spending that would make coins negative.
Offline purchases are provisional: a rejected purchase is removed on sync.
Local changes queue until connection. Keep at least the original device until
its wallet displays “Cloud synced ✓” and the imported coins are visible.

KEYS: The key is kept on the device and in Apps Script properties, not in public
GitHub source. The same configured backend also supports the existing game
save protocol. After connection, each game uploads its current local progress.
If another device has uncached progress only on the old cloud service, open
that game on its original device before migration so its latest save is local.

This assistant prepared the backend but cannot deploy Apps Script through the
available GitHub connection. Cross-device sharing is not active until step 5.
