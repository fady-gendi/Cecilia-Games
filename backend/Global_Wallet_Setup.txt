CECILIA GAMES — BACKEND (version 3.1)

The live server is a Google Apps Script web app (address = ENDPOINT in shared/cecilia.js).
Source code: Cecilia_Auto_Account_CodeGS.txt  (Global_Wallet_CodeGS.txt is an old, unused v2.4 copy.)

Redeploy after changing the code (keeps the same URL):
 1. script.google.com → open the "Cecilia Automatic Account" project.
 2. Replace Code.gs with Cecilia_Auto_Account_CodeGS.txt.
 3. Deploy → Manage deployments → Edit (pencil) → Version: New version → Deploy.
    Execute as: Me. Who has access: Anyone.

What it stores (Google Sheet "Cecilia Global Account"):
 - Ledger: one row per coin event (earn / spend / parent gift / migration), with a unique id.
 - Game_Saves: one row per game profile (latest progress JSON).

v3.1 adds: any new game id can earn and save (sources a-z0-9, profiles cecilia_<name>),
and action=history (coins per game from all devices) for the parent page.
The service is keyless: anyone with the URL can read or change game data. Store no personal data.
