CECILIA GAMES — VERSION 2.6 AUTOMATIC ACCOUNT

The games now connect automatically to the deployed Cecilia Automatic Account.
No family key, Parent connection form, per-device URL, or account-linking step
is required. Open the updated games normally on each browser.

The original Apps Script project and its saved data have not been changed.
The new dedicated backend was deployed by the owner. Its source is in
Cecilia_Auto_Account_CodeGS.txt. It creates and uses its own account spreadsheet.

Existing coins on a browser are imported once per educational game. Local
progress is loaded first, then merged with the server save in the background.
Open each game on the browser where Cecilia already plays so its local progress
can reach the new service. Saves that exist only in the old server are retained
there; this release does not read the old server without its original key.

All six games display one shared coin account. The educational games award
coins; Little World spends them. Fashion Studio remains free play with local
favorite looks. Stars and trophies stay in their individual games.

The service is keyless and restricted to Cecilia's five progress profiles and
virtual coin operations. Anyone who knows its URL can access that game data.
Do not store passwords, contact information or other private data in it.

Offline play saves on the device. Requests retry when the browser reconnects.
Offline purchases remain provisional until confirmed by the server. The ledger
uses stable transaction IDs, serializes changes, and rejects overspending.
